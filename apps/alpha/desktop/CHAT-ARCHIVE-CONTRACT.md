# 채팅방 Git 백업 계약

- `archive_remote_status` 등의 응답에 `chatBackup: "included"`가 있다. 이 값은 채팅방 사본이 Git 저장 범위에 포함된다는 뜻이며, 이미 GitHub에 올라갔다는 뜻은 아니다. 연결 상태와 마지막 전송 시각은 기존 필드로 확인한다.
- `chat_archive_redaction_count({ chatId })`는 해당 채팅방의 마지막 사본에서 가려진 부분 수를 돌려준다. 사본이 없으면 `null`, 읽을 수 없으면 오류 상태다.
- `chat-archive-changed` 이벤트는 `{ chatId, state }`를 준다. `state`는 `saved`(가린 사본을 로컬 파일로 씀) 또는 `unavailable`이다. 창을 닫는 중 저장 실패 알림은 `chatId`가 없다. 사본 작성과 GitHub 전송은 다른 단계다.
- 채팅방 내용과 이름·고정·보관·묶음은 가린 JSON 사본으로 몸소 폴더의 `chats/`에 저장된다. 첨부 원자료의 바이트는 포함하지 않고 번호만 기록한다. 원자료 자체는 별도 원자료 저장소가 필요하다.
- 알려진 비밀값 형태와 몸소 자격 증명 저장소에 든 현재 값은 가리지만, 모든 비밀값을 알아낼 수 있다고 보장하지 않는다. 이미 Git 이력에 올라간 값은 나중에 가려도 옛 이력에서 사라지지 않는다.
- GitHub에 올리기 직전과 앱 창을 닫을 때 바뀐 채팅 사본을 모아 저장한다. 두 PC가 동시에 바꿔 Git 이력이 갈라지면 기존 `diverged` 상태를 그대로 돌려준다.
- Git을 처음 받거나 당겨온 뒤, 그리고 앱 상태를 복원한 뒤 사본을 SQLite에 반영한다. 같은 ID의 로컬 말과 메타데이터는 보존하고 없는 말만 추가한다. 원자료가 아직 없으면 첨부 번호를 보류한다.
