name: object-store-connect
title: 원자료 저장소 연결
description: 원자료를 보관할 곳을 몸소에 연결합니다.
---
사용자가 원자료를 보관할 곳을 연결해 달라고 하면 어느 회사의 계정인지 묻는다. 보관할 곳은 녹음이나 첨부파일처럼 원래 모습을 유지할 자료를 안전하게 두는 공간이라고 설명한다. 사용자에게 어려운 서비스 용어를 그대로 묻지 않는다. 회사 화면에 낯선 이름이 나오면 그 이름이 무엇을 뜻하는지 먼저 한 줄로 풀어 말한다.

Cloudflare R2는 비밀이 아닌 32자리 계정 ID를 물어 `momso_object_store_r2_connect` 도구에 `account`로 넣는다. Google Cloud는 비밀이 아닌 프로젝트 ID를 물어 `momso_object_store_gcp_connect`에 `account`로 넣는다. AWS는 비밀이 아닌 12자리 계정 ID와 지역을 묻고, 연결 정보가 일정 시간이 지나면 만료되는지 확인한다. `momso_object_store_aws_connect`에 `account`, `region`, `credentialType`을 넣는다. 임시 정보는 `temporary`, 그 밖은 `permanent`다. 확실하지 않으면 임의로 고르지 않는다. AWS us-east-1과 NCP는 설정 화면에서 직접 연결하도록 안내한다. 몸소 사용자 이름으로 `momso-사용자이름`을 만들며, 다른 이름을 임의로 고르지 않는다.

연결할 때 계정을 확인하는 비밀 정보가 필요하면 몸소가 여는 보안 입력에 사용자가 직접 넣도록 안내한다. 비밀 정보나 비밀번호, 인증 번호를 채팅에 적으라고 하지 않고 도구 인자에 넣지 않는다. 회사, 계정, 지역, 새로 만들 이름과 비용 가능성을 승인 카드에서 확인하고 사용자가 한 번 허락할 때까지 기다린다. 같은 이름이 이미 있거나 정보가 달라지면 기존 보관할 곳을 읽거나 고치지 않고 멈춘다. 거절하거나 중단하면 실행하지 않는다. 승인되지 않은 셸 명령이나 다른 서비스를 사용해 돌아가지 않는다. 도구가 없거나 실패하면 연결되었다고 말하지 않는다.
