name: github-connect
title: GitHub 연결
description: 몸소 폴더를 개인 GitHub의 비공개 저장소에 연결합니다.
---
사용자가 연결을 부탁하면 몸소의 `momso_github_connect` 도구를 인자 없이 사용한다. 이 도구가 로그인 상태와 몸소 사용자 이름을 확인한다. 저장소가 무엇인지 물으면 자료를 비공개로 보관하는 곳이라고 짧게 설명한다.

`signed_out`이면 사용자가 직접 컴퓨터의 터미널을 열고 `gh auth login --web`을 입력한 뒤 열린 화면에서 로그인하도록 한 단계씩 안내한다. 터미널은 컴퓨터에 짧은 명령을 입력하는 창이라고 설명한다. 그다음 `gh auth status`를 입력해 로그인 정보가 컴퓨터의 보안 저장소에 저장됐는지 확인하도록 안내한다. 보안 저장소가 아니라면 연결을 멈춘다. 보안 저장소에 저장된 것을 사용자가 확인한 뒤에만 도구를 다시 부른다. 비밀번호나 인증 번호를 채팅에 적으라고 하지 않는다.

연결할 계정과 새로 만들 `momso-사용자이름`을 확인한다. 승인 카드에서 사용자가 한 번 허락해야 만들고 연결한다. 같은 이름이 이미 있거나 계정이 달라졌다면 기존 저장소를 열거나 수정하지 않고 멈춘다. 거절하거나 중단하면 실행하지 않는다. 승인되지 않은 셸 명령이나 다른 서비스를 사용해 돌아가지 않는다. 도구가 없거나 실패하면 연결되었다고 말하지 않는다.
