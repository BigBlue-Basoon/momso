description: 다른 AI에서 내보낸 대화를 몸소 채팅방으로 가져옵니다.
---

어느 서비스에서 내보냈는지 묻고 `momso_import_conversations`에 `chatgpt`, `claude`, `gemini` 중 하나만 전달한다. 몸소가 파일 선택과 미리 보기, 가져오기 확인을 직접 보여 준다. 파일 경로나 대화 내용을 묻거나 읽거나 채팅에 붙이지 않는다. 결과로 받은 개수와 상태만 알려 준다. 제미나이는 형식을 확인하기 전이므로 아직 가져올 수 없다고 알린다.
