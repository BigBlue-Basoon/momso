선생님이 홍보할 수업과 올릴 곳을 묻는다. 한 곳만 원하면 그곳만, 여러 곳을 원하면 선택한 곳만 준비한다. 선생님이 고른 수업 기록·문서·사진과 동영상에서 필요한 재료만 찾고 확인한다. 확인하지 못한 일정, 가격, 효과나 사진을 지어내지 않는다. 재료가 부족하면 묻는다.

선택한 곳마다 바로 복사할 수 있게 나누어 쓴다.
- 인스타그램: 짧은 글과 알맞은 해시태그.
- 네이버 블로그: 제목과 긴 본문.
- 네이버 스마트플레이스 소식: 짧은 알림 글.
- 카카오톡 채널 소식: 짧은 알림 글.

고른 사진을 함께 제안하거나, 사진이 없으면 사진을 고르거나 만들기를 권한다. 수강생의 얼굴이 보이면 올려도 되는지 그 사람에게 확인하도록 알린다. 사진을 직접 만들 수 없는 경우 만들었다고 말하지 않는다.

선생님이 확인할 수 있도록 결과를 하나의 몸소 문서로 저장한다. 먼저 `zet_folders`로 기존 폴더를 확인한다. `홍보` 폴더가 있으면 `momso_document_create`에 `title`, `summary`, `body`와 `folder: "홍보"`를 넘긴다. 알맞은 기존 폴더가 없으면 `folder`를 생략해 맨 위에 저장하고 새 폴더는 만들지 않는다. 몸소의 승인 요청을 따른다. 본문은 올릴 곳별로 나누고 사진의 출처나 선택 정보를 적는다. 저장에 실패하거나 도구가 없으면 저장했다고 말하지 말고 준비한 글을 보여 주며 저장하지 못한 까닭을 알린다.

마지막 답변과 저장할 문서에 선택한 곳 각각의 공식 입구 주소를 아래에서 그대로 복사해 빠짐없이 적는다. 사이트 이름만 적거나 주소를 생략하지 않는다. 선택하지 않은 곳의 주소는 넣지 않는다. 선생님이 해당 주소에서 직접 로그인해 글과 사진을 올리고 게시하도록 안내한다. 업체별 편집 주소나 버튼 순서는 추측하지 않는다.

- 네이버 블로그: https://blog.naver.com/
- 네이버 스마트플레이스: https://smartplace.naver.com/
- 카카오톡 채널 관리자센터: https://center-pf.kakao.com/

이 스킬에서는 외부 사이트에 로그인하거나 글을 입력하거나 사진을 업로드하거나 게시를 누르지 않는다. 이 안내는 브라우저 사용이나 사이트 접근 범위를 제한하지 않는다.
