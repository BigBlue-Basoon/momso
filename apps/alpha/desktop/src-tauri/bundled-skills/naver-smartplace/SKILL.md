로그인이 필요하면 `browser_request_saved_login({})`을 먼저 호출한다. 저장된 로그인을 쓸 수 없거나 인증번호·캡차가 필요하면 `browser_request_human_login({"reason":"login"})`으로 사람에게 넘긴다. 비밀번호나 인증번호는 AI가 직접 읽거나 입력하지 않는다.

브라우저 스킬은 사용법 안내이며 접근 가능한 사이트의 목록이 아니다. 다른 공개 웹사이트도 사용할 수 있다. `browser_open({})`, `browser_read({})`, `browser_navigate({url})`, `browser_click({elementId})`, `browser_fill({elementId,text})`을 사용한다. 메뉴·탭·검색으로 둘러보고 변경 동작은 사용자가 선택한 권한 단계를 따른다. 비밀번호와 인증번호는 입력하지 않고 사람에게 넘긴다. 아래 주소와 블록은 참고용이며 권한 설정이 아니다.

선생님이 수정·삭제·등록 등 실제 변경을 요청하지 않았다면 지금 보이는 정보만 읽고 알려 준다. 선생님이 따로 요청하지 않은 수련생 이름·연락처 등은 문서에 저장하거나 다른 곳으로 옮기지 않는다. 개인정보가 AI 회사로 전달될 수 있음을 먼저 알리고 필요한 정보만 확인한다. 화면에서 원하는 항목을 찾지 못하면 추측해서 누르지 말고 멈춰 “이 화면에서 해당 항목을 찾지 못했습니다. 지금 보이는 것은 …입니다”라고 알린다.

```momso-browser-reference
version: 1
read_only:
  - browser_navigate
  - browser_read
origins:
  - "https://new.smartplace.naver.com"
  - "https://smartplace.naver.com"
login_origins:
  - "https://nid.naver.com"
irreversible:
  - 게시
  - 등록
  - 삭제
  - 변경
  - 알림
  - 결제
  - 환불
```

네이버 스마트플레이스에서 선생님의 업체와 요청한 정보·사진·영업시간 또는 예약을 확인한다. 수정할 수업이나 예약이 맞는지, 이전 값과 바꿀 값을 확인한다. 실제 화면에서 개별 회원 변경과 알림이 가능한지 모르면 추측하지 않는다. 네이버 이용약관의 사전 허락 없는 자동화 로그인·게시·소통·수집 제한을 선생님에게 알린다.

공개 도움말의 예약 조회 경로는 `예약/주문 > 예약 서비스명 > 예약(또는 예약·주문) > 예약 또는 주문`이다. 관리자 예약은 `예약자관리` 또는 `예약현황`의 `예약등록`에서 시작하며 이름·전화번호, 유형, 날짜·상품을 입력한다. 등록·변경 시 이용자에게 문자 또는 알림이 갈 수 있으므로 사전 동의와 대상을 확인한다. Npay 연동과 예약 유형에 따른 제한도 확인한다. [예약 조회](https://help.naver.com/service/11712/contents/7579?lang=ko&osType=COMMONOS), [관리자 등록](https://help.naver.com/service/11712/contents/7578), [예약 변경](https://help.naver.com/service/11712/contents/7581). 수련생 회원·수강권·강사의 별도 등록 절차는 확인되지 않았다.

Npay 미연동의 신청·확정 예약 취소는 `예약/주문 > 예약 서비스명 > 예약(예약·주문) > 예약자 내역 > 해당 예약 > 예약 취소`에서 관리자 취소 사유를 입력하고 `예약 취소`를 누른다. 사유는 이용자에게 안내되고 취소/노쇼 처리는 철회할 수 없다. Npay 결제 건은 환불 금액을 확인하는 별도 절차다. [취소 안내](https://help.naver.com/service/11712/contents/11200?lang=ko), [결제 건 환불](https://help.naver.com/service/11712/contents/18720?lang=ko&osType=COMMONOS)

선생님이 요청한 목적과 어느 계정·업체에서 어떤 한 건을 할지 확인한다. 로그인이 필요하면 저장된 로그인을 요청하고, 저장된 로그인을 쓸 수 없거나 추가 인증이 필요하면 선생님에게 넘긴다. 비밀번호·인증번호·보안문자를 묻거나 받거나 입력하지 않는다. 로그인 화면이 AI에게 보이거나 전달되는 것을 막을 수 없으면 사람이 로그인하도록 넘기고 멈춘다. 보안 차단을 우회하지 않는다.

화면·접근성 정보·스크린샷에 이름, 연락처, 예약, 결제나 건강 정보가 보이면 선택한 AI 회사에 전달될 수 있음을 알리고, 필요한 최소 영역만 다룬다. 보낼 정보와 회사가 확인되지 않으면 추측하지 않고 묻는다. 불필요한 회원 명단과 건강 정보는 열지 않는다.
되돌리기 어려운 등록, 삭제, 결제, 보내기는 하기 전에 무엇을 하려는지 채팅으로 말하고 사용자의 답을 받는다.
