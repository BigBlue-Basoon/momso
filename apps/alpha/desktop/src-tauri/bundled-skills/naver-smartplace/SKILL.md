title: 네이버 스마트플레이스 운영
description: 네이버에 등록한 업체 정보와 예약을 확인하고 수정하도록 돕습니다.
---

선생님이 수정·삭제·등록 등 실제 변경을 요청하지 않았다면 지금 보이는 정보만 읽고 알려 준다. 선생님이 따로 요청하지 않은 수련생 이름·연락처 등은 문서에 저장하거나 다른 곳으로 옮기지 않는다. 개인정보가 AI 회사로 전달될 수 있음을 먼저 알리고 필요한 정보만 확인한다. 화면에서 원하는 항목을 찾지 못하면 추측해서 누르지 말고 멈춰 “이 화면에서 해당 항목을 찾지 못했습니다. 지금 보이는 것은 …입니다”라고 알린다.

```momso-browser-policy
version: 1
read_only:
  - browser_navigate
  - browser_read
origins:
  - "https://new.smartplace.naver.com"
  - "https://smartplace.naver.com"
irreversible:
  - 게시
  - 등록
  - 삭제
  - 변경
  - 알림
  - 결제
  - 환불
```

선생님이 변경을 요청하면 실제 화면에서 해당 작업의 버튼을 확인하고 `browser_request_action`에 정책의 작업 이름, 선생님이 요청한 구체적인 설명, 버튼의 `elementId`를 넣어 몸소의 승인을 요청한다. 거절하면 읽기만 한다. 승인 뒤에도 누르기와 입력은 한 번씩 따로 승인받는다. 화면을 찾지 못하거나 작업이 다르면 중단한다.

네이버 스마트플레이스에서 선생님의 업체와 요청한 정보·사진·영업시간 또는 예약을 확인한다. 수정할 수업이나 예약이 맞는지, 이전 값과 바꿀 값을 확인한다. 실제 화면에서 개별 회원 변경과 알림이 가능한지 모르면 추측하지 않는다. 네이버 이용약관의 사전 허락 없는 자동화 로그인·게시·소통·수집 제한을 선생님에게 알린다.

선생님이 요청한 목적과 어느 계정·업체에서 어떤 한 건을 할지 확인한다. 선생님이 회사의 공식 화면에서 직접 로그인하고 인증한다. 비밀번호·인증번호·보안문자를 묻거나 받거나 입력하지 않는다. 로그인 화면이 AI에게 보이거나 전달되는 것을 막을 수 없으면 사람이 로그인하도록 넘기고 멈춘다. 보안 차단을 우회하지 않는다.

화면·접근성 정보·스크린샷에 이름, 연락처, 예약, 결제나 건강 정보가 보이면 선택한 AI 회사에 전달될 수 있음을 알리고, 필요한 최소 영역만 다룬다. 보낼 정보와 회사가 확인되지 않으면 추측하지 않고 묻는다. 불필요한 회원 명단과 건강 정보는 열지 않는다.

변경을 준비한 뒤 회사·계정·대상·현재 값·변경할 값·공개 범위·알림·비용·되돌릴 수 없는 효과·개인정보 전달을 선생님이 확인하게 한다. 게시, 삭제, 회원·예약 변경, 알림 발송, 결제·환불 등 외부에 영향을 주는 행동 직전에 몸소의 승인 카드에서 그 변경 한 건만 허락받는다. 자동 권한이더라도 승인을 건너뛰지 않는다. 내용·대상·계정·비용이나 알림이 달라지면 다시 확인받는다. 모르는 항목은 모른다고 표시한다.

몸소가 제공하는 브라우저 조작 도구와 정확한 변경을 묶는 승인 카드가 둘 다 없거나, 로그인 정보 보호가 확인되지 않으면 실제 화면 조작을 진행하지 말고 현재 무엇이 필요한지 알린다. 특정 버튼 위치를 외우지 말고 화면에서 목적과 대상을 확인한다. 화면이 바뀌어 찾지 못하거나 대상이 모호하면 중단해 선생님께 넘긴다. 승인 거절·중단 시 아무것도 바꾸지 않는다. 결과가 불명확하면 재전송하지 말고 확인한다. 결과를 확인하지 못했으면 완료라고 말하지 않는다.
