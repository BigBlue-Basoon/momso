# 소유자 세션의 VM 크기 변경 연결 (S163)

현재 소유자 세션은 입구의 `__Host-momso-session` HttpOnly 쿠키다. `scripts/momso_anywhere_gateway.py`는 이 세션을 확인한 뒤 쿠키를 제거하고 사설 통로로 보낸다. 휴대폰에서 같은 출처로 요청하면 세션을 입구에 자동으로 보낼 수 있지만, VM 밖에서 실행하는 `scripts/momso_anywhere_resize.py`가 그 쿠키를 안전하게 받을 수 있는 연결은 없다. 현재 스크립트의 `--owner-session-file`은 이 문제를 해결한 제품 경로가 아니다.

크기 변경은 서버가 설치된 VM을 멈추므로 VM 안의 요청 처리기만으로 끝낼 수 없다. 현재 입구에 부여된 VM 권한은 `compute.instances.get`과 `compute.instances.start`뿐이며, 중지와 크기 변경 권한은 없다. 입구가 요청을 처리하다 끊기거나 다시 시작되더라도 VM이 멈춘 채 남지 않도록 상태와 복구를 VM 밖에 지속적으로 보관해야 한다. 기존 유지보수 잠금, 자동 깨우기, 업데이트 및 백업과도 충돌하지 않아야 한다.

휴대폰에서 크기 바꾸기: 입구 권한을 넓혀야 해서 보류, 화면 볼 때 정함. 필요한 연결은 소유자 세션과 동일 출처 검사를 거친 변경 요청, 해당 VM에만 제한된 제어 권한, VM 밖의 지속되는 작업·복구 기록, 유지보수 잠금 소유권, 재시작 뒤 같은 소유자 세션을 이용한 입구 상태 확인이다. 성공·복구·확인 불가를 구분해 내보내야 한다. 이를 위한 권한 배포와 장애 복구 경로는 아직 구현되지 않았고 실제 입구에서 크기 변경은 수행하지 않았다. 기존 입구의 인증을 생략하거나 고객 VM의 권한을 임의로 넓히지 않는다.
