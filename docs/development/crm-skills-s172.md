## 나머지 내장 스킬 점검

11개 중 대상 세 개를 뺀 8개를 읽었다. 이 점검은 각 서비스의 공식 문서를 새로 전수 조사한 것이 아니다. 출처를 이 점검에서 대조하지 못한 외부 화면 단계는 **1개**(대화 가져오기), 사이트 접근 제한으로 읽힐 수 있는 문구는 **1개**다. 확인하지 못한 단계가 틀렸다고 단정하지 않는다.

| 스킬 | 점검 결과 |
|---|---|
| 프립, 숨고, 스튜디오메이트, 솜씨당 | 4개 모두 고정된 관리자 메뉴 순서는 적지 않고 화면을 확인하도록 함. 참고 주소·로그인 주소와 개별 서비스 약관 표현은 이번에 진위를 재검증하지 않았으므로 미확인. 브라우저 접근을 제한하지 않는다는 문구가 있음. |

## 데스크톱과 서버

두 제품은 `momso-core/src/skill.rs`의 `BUNDLED_SKILLS`가 컴파일할 때 포함하는 같은 세 파일을 사용한다. 서버 `Cargo.toml`은 그 `momso-core`를 사용하며 `filesystem::initialize` → `install_bundled_skills`가 같은 설치기를 부른다. 새 프로필의 실제 저장본이 세 내장 파일과 같은지 S166 시험에서 비교한다. 기존 사용자 파일이 직전 내장본과 다르게 편집돼 있으면 설치기가 덮어쓰지 않으므로 새 안내서가 자동 반영되지 않을 수 있다. 데스크톱과 서버 모두 그 보존 규칙을 따른다.

## 연습 시험의 해석

수정된 파일을 포함해 빌드한 서버가 새 시험 프로필에 세 파일을 정확히 설치했는지 비교하고 S166의 실제 헤드리스 브라우저·가짜 Codex 경로를 다시 실행한다. 가짜 Codex는 정해진 대본을 사용하므로 AI가 새 안내서를 이해해 자율적으로 따르는 능력을 증명하지는 않는다. 실제 바디코디 계정·화면은 시험하지 않는다.

## S176 후속 확인

- 대화 가져오기: [Google Gemini 앱 데이터 다운로드 안내](https://support.google.com/gemini/answer/16920332?hl=ko)는 채팅 등 Gemini 앱 활동을 내보낼 때 `내 활동`을 선택하고 `모든 활동 데이터 포함됨`에서 `Gemini 앱`을 선택하도록 안내한다. 따라서 기존 선택 단계는 유지했다. [Google 데이터 다운로드 안내](https://support.google.com/accounts/answer/3024190?hl=ko)는 제품별 데이터와 형식을 선택할 수 있다고 설명하지만, 이 두 공개 도움말에서 `내 활동`의 JSON 선택 가능 여부는 확인하지 못했다. 실제 계정 로그인이나 내보내기는 하지 않았다. 확인일: 2026-11-25.
- 홍보 글 준비: 기존의 직접 게시하지 않는 작업 범위는 유지하고, 브라우저 사용이나 사이트 접근 범위를 제한하지 않는다는 뜻을 명확히 했다. 스킬 목록의 이름과 설명은 바꾸지 않았다.
- 충실도 대조: Gemini 앱 선택 주체·경로는 공식 도움말과 일치하고, 홍보 글의 게시 담당과 브라우저 접근 원칙은 각각 기존 안내와 사용자 결정에 맞다. 의미 변형은 발견하지 못했다. JSON 선택 가능 여부는 미확인으로 남긴다.
